# 🐶 Dog Adventure – Unity Game Project

**Dog Adventure** là một trò chơi phiêu lưu nơi bạn điều khiển một chú chó dễ thương khám phá thế giới, thu thập vật phẩm và vượt qua các thử thách thú vị. Trò chơi được phát triển bằng **Unity** và hỗ trợ build cho thiết bị **Android**.

---

## 📂 Cấu trúc thư mục

- `/Assets`: File C# cho các tính năng trong game
- `/Image`: Hình ảnh sử dụng trong gameplay và UI
- `/Sound`: Âm thanh hiệu ứng và nhạc nền
- `Dog Aventure Game.apk`: File APK cài đặt game lên Android
  
---

## 🎮 Giới thiệu trò chơi

Trong **Dog Adventure**, người chơi vào vai một chú chó nhỏ khám phá thế giới xung quanh. Nhiệm vụ của bạn gồm:

- Thu thập vật phẩm
- Tránh các chướng ngại vật
- Vượt qua các đoạn đường thử thách
- Đạt điểm cao nhất có thể

Game có phong cách đồ họa pixel dễ thương, điều khiển đơn giản, phù hợp với mọi độ tuổi.

---

## 📱 Cài đặt trò chơi (Android)

Tải file APK:

👉 **[Dog Adventure Game.apk](Dog%20Aventure%20Game.apk)**

**Lưu ý:**  
- Hãy bật *Install from Unknown Sources* để cài đặt.  
- File APK build từ Unity nên tương thích với hầu hết thiết bị Android.
